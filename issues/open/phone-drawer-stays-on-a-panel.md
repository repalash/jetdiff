# On a phone, the drawer stays on the Commit, Shelf or pull requests panel

The side strip (Commit, Changes, Pull Requests) is hidden on a phone. Once the drawer shows the Commit tool window
(from the Commit button over the diff, or a toast's Show) or the pull requests (from the project menu), the ☰ button
opens it on that panel again: the changed files come back only through Search Everywhere's "Changed Files" or by
opening a pull request from the list. The drawer could offer the panels the strip does, for one.
