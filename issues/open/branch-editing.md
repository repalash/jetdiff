# Editing a branch, not only a pull request

Decided (Q24–Q26), not built:
- the branch popup, as in the IDE, with New Branch…; `?branch=`, `/tree/` and `/blob/` links;
- the full file tree of the branch and a single-file view;
- edits and new files, committed with the existing Commit panel;
- edits are kept per branch and shared with the pull request view of that branch (no migration of the per-PR edits).

Later: delete and rename files, open a pull request from a new branch, Checkout Tag or Revision, search in file contents.
